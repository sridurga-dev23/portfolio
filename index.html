Air Pollution Monitoring System

Developed a system to monitor air quality and support pollution control by tracking environmental conditions.

Arduino IDE ESP8266 Blynk IoT MQ135 Sensor

Project Description

The Air Pollution Monitoring System is an IoT-based project that monitors air quality using the MQ135 gas sensor and ESP8266 NodeMCU. The collected sensor data is transmitted to the Blynk IoT platform through Wi-Fi, enabling users to monitor air pollution levels in real time from a mobile device.

Features

  • Real-time Air Quality Monitoring
  • Pollution Level Analysis
  • Graphical Reports
  • Responsive Dashboard

Technologies Used

  • Arduino IDE – Programming and uploading code.
  • ESP8266 NodeMCU – Wi-Fi enabled microcontroller.
  • Blynk IoT – Cloud platform for real-time monitoring.
  • Blynk Library – Communication between hardware and Blynk app.
  • MQ135 Gas Sensor – Detects air quality and harmful gases.
